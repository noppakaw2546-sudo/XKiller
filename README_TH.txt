X KILLER — SOURCE PROJECT 1.2
=============================

สิ่งที่โปรเจกต์นี้ทำได้
- หน้าหลัก X KILLER ธีมดำ/ขาว
- ปุ่มเปิดหน้า Accessibility Settings ของ Android
- เปิด/ปิดไอคอนลอย X พร้อมลากย้ายตำแหน่งได้
- ไอคอนลอยแตะแล้วเปิดหน้า Accessibility Settings
- แถบ Contrast, Brightness และ White Tone บันทึกค่าที่เลือกไว้ในแอป
- ปุ่มคืนค่าเริ่มต้น
- Floating service ทำงานเป็น foreground service พร้อม notification เพื่อลดโอกาสถูกระบบปิด

ข้อจำกัดสำคัญ (อ่านก่อนติดตั้ง)
1. โปรเจกต์นี้ยังไม่ใช่ APK และยังไม่ได้ผ่านการ Build/ทดสอบบนโทรศัพท์จริง
2. แอปทั่วไปไม่สามารถสั่งเปิด/ปิด Color Inversion ระดับระบบเองได้อย่างอิสระ ต้องให้ผู้ใช้เปิดจาก Accessibility Settings ด้วยตนเอง
3. แถบ Contrast / Brightness / White Tone ในรุ่นนี้เป็นค่าพรีเซ็ตที่บันทึกในแอปเท่านั้น ยังไม่เปลี่ยนภาพเกมหรือแอปอื่น
4. ไอคอนลอยเป็นทางลัดไปยัง Accessibility Settings ไม่ใช่สวิตช์กลับสี
5. การทำให้เฉพาะศัตรูเป็นสีขาวโดยไม่เปลี่ยนฉากต้องอาศัยการประมวลผลภาพแบบเรียลไทม์ ซึ่งโปรเจกต์นี้ยังไม่มี และไม่สามารถรับประกันการทำงานร่วมกับทุกเกมได้
6. แอปนี้ไม่มีระบบตรวจจับศัตรูหรือแสดงตำแหน่งผ่านกำแพง

การ Build APK
- ต้องใช้ Android Studio/สภาพแวดล้อมที่มี Android SDK
- Android Gradle Plugin 8.6.1, Gradle 8.7 หรือใหม่กว่า, JDK 17
- ต้องติดตั้ง Android SDK Platform 35
- เปิดโฟลเดอร์ XKiller ใน Android Studio แล้วเลือก Build > Build APK(s)
- ผลลัพธ์โดยทั่วไป: app/build/outputs/apk/debug/app-debug.apk

การใช้งานหลังติดตั้ง
1. เปิด X KILLER แล้วกดเปิดไอคอนลอย
2. อนุญาตสิทธิ์แสดงทับแอปอื่นเมื่อระบบถาม
3. กลับเข้าแอปแล้วกดเปิด Accessibility Settings หรือแตะไอคอน X
4. เปิด Color inversion ด้วยตนเองในเมนู Accessibility ของโทรศัพท์
5. ปิดไอคอนลอยจากปุ่มในแอป

หมายเหตุ: การตั้งชื่อเมนูและตำแหน่ง Color inversion อาจต่างกันตามยี่ห้อ/เวอร์ชัน Android
